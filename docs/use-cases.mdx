## Memory for coding agents

Register memloom as an MCP server ([setup](/mcp/setup)) and the agent gets `save_memory` and
`recall_memory` backed by your store.

<CardGroup cols={3}>
  <Card title="It remembers" icon="brain">
    "deploys go through `scripts/release.sh`, never manual" saved once, recalled in every later
    session.
  </Card>
  <Card title="Across tools" icon="arrows-left-right">

## A second brain your agents share

```bash
memloom context add ./notes
```

If you know NotebookLM, this is that idea, but local, open source, and readable by every agent
you connect.

| | |
| --- | --- |
| **Recallable both ways** | By meaning and by exact phrase, cited back to file, section and page |
| **One copy** | Every tool reads the same store instead of keeping its own partial one |
| **Stays in step** | Re-run `context add`: changed files re-ingest, unchanged ones are skipped |
