## Where config lives

```
~/.memloom/config.env
```

Created by `memloom init`, dotenv-style, read **at startup**. Restart after editing. Real
environment variables win over the file, so a shell or MCP key overrides what is written there.
`MEMLOOM_HOME` relocates the whole directory, config and data together.

***

## The settings that matter

```bash
OPENROUTER_API_KEY=sk-or-...        # the one switch: with it, cloud mode. Without it, offline
```

| Setting | Default | For |
| --- | --- | --- |
| `OPENROUTER_EMBED_MODEL` | `qwen/qwen3-embedding-8b` | Embeddings |
| `OPENROUTER_EMBED_DIMS` | `1024` | Matryoshka truncation from the native 4096 |
| `OPENROUTER_LLM_MODEL` | `google/gemini-2.5-flash` | The pipeline's classifier and extractors |
| `OPENROUTER_CHAT_MODEL` | same as above | The assistant. Must support tool calling |
| `MEMLOOM_AUTO_INDEX` | `on` | Background entity extraction after saves and ingests |
| `MEMLOOM_INDEX_CONCURRENCY` | `6` | Extraction worker pool size |
| `RECONCILE_ENABLED` | unset | Set to `0` to keep the reports and refuse the repairs |
| `MEMLOOM_PG_URL` | unset | Run on a real Postgres instead of the embedded store |

The full annotated list, including transcription and diarization, lives in
`config.env.example` in the repo and in the file `memloom init` writes.

<Accordion title="Notes on three of them" icon="circle-info">
  **`MEMLOOM_AUTO_INDEX`** covers the indexing that runs a few seconds after a save or ingest, one
  model call per new item, debounced. Set it `off` to make every call explicit. `memloom index`
  still works. Offline never auto-indexes.

  **`RECONCILE_ENABLED=0`** is a kill switch, not the switch.
  [Reconciliation](/concepts/reconciliation) is on by default with its two free passes, and which
  passes run is a viewer setting that needs no restart. Setting `0` makes an applying run fail
  with a 403 and stops automatic runs acting. Previews keep working.

  **`OPENROUTER_EMBED_PROVIDER`** exists because embedding latency varies wildly between hosts of
  the same model: the same call has been seen taking 16 seconds on one and under a second on
  another. memloom pins the fast host for the default model, so set this only if you change
  models.
</Accordion>

## The two modes

| | Cloud (key set) | Offline (no key) |
| --- | --- | --- |
| Embeddings | Real model | Deterministic hash |
| Recall | Full semantic | Word overlap, with the keyword arm at full quality |
| Dedup and versioning | Yes | No, every save is `added` |
| Conflict detection | Yes | No |
| `memloom index` | Yes | No, it needs a model |
| Context ingestion and citations | Yes | Yes |
| Network calls | Embedding and model requests | None |

Offline is for trying memloom, tests, and air-gapped keyword search. For real use, set the key.

***

## The embedding fingerprint

Vectors are only comparable to vectors from the same provider, model and dims, so the store is
stamped on first init, for example `openrouter:qwen/qwen3-embedding-8b@1024`. A later startup with
a different fingerprint is refused.

<Warning>
  This is deliberate. Mixed embedding spaces do not fail with an error, they silently return
  garbage recall.
</Warning>

Changing model is a migration, not a dead end: stop the daemon and run
[`memloom reembed`](/cli/graph), which recomputes every vector and stamps the new fingerprint. The
LLM model can be changed freely, since it never touches the vector space.

## Daemon endpoints

| What | Where | Movable |
| --- | --- | --- |
| HTTP API and viewer | `http://127.0.0.1:4319` | No, localhost only by design |
| Postgres wire | `postgresql://postgres@127.0.0.1:54329/postgres` | `MEMLOOM_PG_PORT`, embedded tier only |

Both bind to `127.0.0.1`, and CORS admits only localhost origins, so a public web page cannot
drive your daemon.

<Accordion title="If the wire port will not bind on Windows" icon="windows">
  Hyper-V, WSL and Docker reserve random 100-port blocks inside the ephemeral range at every boot,
  and one can land on 54329. The daemon then starts without the wire and prints why, so the API
  and viewer keep working.

  Set `MEMLOOM_PG_PORT` to a free port below 49152 and restart.
  `netsh interface ipv4 show excludedportrange protocol=tcp` lists the blocked ranges.
</Accordion>
